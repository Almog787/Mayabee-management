## 📌 אודות המערכת
מערכת ניהול חכמה ומהירה עבור מעון הילדים **"הגן של רותם ומאיה"** (תקן 40 ילדים | אריאל).  
המערכת מיועדת לתכנון מאזן חודשי, תמחור רב-גילאי (תינוקייה ופעוטון), ניתוח נקודת איזון (Break-Even), חלוקת שותפות שקופה, חישוב רווח נקי לפני ואחרי מס, וייצוא חכם לקובצי גוגל שייטס / אקסל מעוצבים עם נוסחאות אוטומטיות.

---

## 🚀 תכונות מרכזיות
- **מתכנון מאזן חודשי צפוי:** חישוב הכנסות (שכר לימוד וצהרונים) מול הוצאות קבועות (שכירות, ארנונה, ביטוח, חשמל) והוצאות משתנות (מזון, חומרי יצירה, היגיינה ושכר צוות).
- **מחשבון מס מוערך (רשות המיסים):** חישוב בזמן אמת עבור עוסק פטור, עוסק מורשה, או חברה בע"מ (כולל רווח נקי לפני מס, חבות מס הכנסה, ביטוח לאומי, ורווח נטו סופי שנשאר בכיס).
- **ייצוא חכם לגוגל שייטס (Google Sheets / Excel):** יצירת גיליון חכם מעוצב עם נוסחאות מתמטיות אוטומטיות לניהול ומעקב.
- **שיתוף בווטסאפ (WhatsApp Share):** יצירת דוח עברי מעוצב ושילוח בלחיצת כפתור אחת.
- **שמירה מקומית (Local-First):** סנכרון אוטומטי בתוך הדפדפן ללא צורך בהתחברות או הרשמה.
