## 1. שלב א' (Phase 1) - מצב נוכחי (Active Demo & Production Core)
* **ארכיטקטורה:** Local-First / Client-Side Web Application ב-React 19, TypeScript ו-Tailwind CSS v4.
* **אחסון מקומי חסין:** Dexie.js (IndexedDB) מופרד Origin בנתיב המאגר, ללא הגבלת נפח של 5MB (כמו ב-localStorage).
* **אבטחה והצפנה במנוחה:** Web Crypto API (AES-GCM 256-bit) להצפנת שדות רפואיים, תעודות זהות ונתונים פיננסיים רגישים.
* **עבודה לא מקוונת (PWA):** Service Worker, Manifest, אייקונים והתקנה מלאה למסך הבית במחשב ובנייד.
* **מודולים פעילים:**
  1. לוח בקרה למנהלת (Dashboard).
  2. ילדים ומשפחות (10 ילדים, פרטי הורים, אלרגיות, מעקב יומי ויצירת סיכום וואטסאפ).
  3. יומן נוכחות יומי (כניסה/יציאה).
  4. כספים וחשבונות (שכ"ל, מעקב עוסק פטור 122,000 ₪, חוק המזומן 6,000 ₪, הפקת קבלות).
  5. צוות ועובדות (שעון נוכחות, תקינת יחס פיקוח, תוקף עזרה ראשונה ואישורי משטרה).
  6. תזונה ובטיחות (תפריט משרד הבריאות, הצלבת אלרגנים, צ'קליסט בטיחות וממ"ד).
  7. יועץ רגולטורי AI (חיפוש חוקי עבודה, תקנות פיקוח ומיסוי מעודכנים מ-Google Search).

## 2. שלב ב' (Phase 2) - סנכרון ענני Google Sheets (Google Apps Script API)
כאשר המנהלת תחליט להפעיל סנכרון ענני מלא ללא שרת חיצוני:
* **טכנולוגיה:** Google Apps Script Web App עם חיבור REST (`doGet` / `doPost`).
* **שרת פרוקסי מקומי:** `/api/sheets/proxy` העוקב אחר הפניות 302 של Google ומונע בעיות CORS בדפדפן.
* **מבנה 7 הלשוניות בגליון:**
  1. `📊 דשבורד_מנהלת` - כרטיסי KPI, מד עוסק פטור, יחס תקינת מטפלות.
  2. `👶 ילדים` - מאגר ילדים ופדגוגיה.
  3. `📅 נוכחות` - יומן נוכחות יומי ומצטבר.
  4. `💰 כספים` - תקבולים, הוצאות מוכרות, קבלות פנימיות וסימון אדום לחריגות מזומן.
  5. `👩‍🏫 צוות` - פרטי עובדות, שכר שעתי, תוקף קורסי עזרה ראשונה.
  6. `🥗 תזונה_ובטיחות` - תפריט שבועי, מנות חלופיות לאלרגנים.
  7. `⚙️ הגדרות` - פרמטרי המעון, מנהלת ופרטי קשר.
* **מנגנון סנכרון:** Last-Write-Wins (LWW) מבוסס חותמות זמן ISO ו-UUID v4.

## 3. שלב ג' (Scale Phase) - סקייל לעשרות/מאות ילדים וחיבור שירותים מורשים
כאשר המעון יתרחב לקבוצות נוספות או סניפים:
1. **Backend סרוורלס ייעודי:**
   * מעבר ל-Supabase (PostgreSQL) או Cloudflare Workers + D1.
   * אימות משתמשים רב-שכבתי (מנהלת ראשית, גננות, סייעות, הורים).
2. **חיבור שירותי סליקה וחשבוניות מורשות (רשות המסים):**
   * Morning (חשבונית ירוקה) / Green Invoice / iCount.
   * חיבור API להנפקת קבלות מס דיגיטליות חתומות עם מספר הקצאה של רשות המסים (חשבוניות ישראל).
   * סליקת אשראי והוראות קבע מאובטחות (PCI-DSS) לשכר לימוד חודשי.
3. **פורטל הורים ייעודי (Parent App):**
   * אזור אישי להורים לצפייה בדיווחי יום, תמונות מאובטחות, תפריט ואישורי הגעה.
